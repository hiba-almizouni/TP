# TP3 – CinemaManager (Jointures & Filtres)

## Description
Extension du TP2 : jointures entre entités via propriétés de navigation et ViewModel, filtres de recherche avancée avec LINQ.

## Nouvelles fonctionnalités
- `MoviesAndTheirProds` : jointure par propriétés de navigation
- `MoviesAndTheirProds_UsingModel` : jointure LINQ avec ViewModel `ProdMovie`
- `MyMovies(id)` : films d'un producteur donné
- `SearchByTitle`, `SearchByGenre` : filtres LINQ
- `SearchBy2` : double filtrage Genre + Titre avec DropDownList

## Technologies
- .NET 8.0 · ASP.NET Core MVC · EF Core 8 · LINQ · SQL Server LocalDB
