# TP6 – SchoolAPI (Web API / DTO / Repository Pattern)

## Description
Solution en deux projets :
- **SchoolAPI** : API RESTful ASP.NET Core avec Swagger, EF Core Code First, AutoMapper, Repository Pattern
- **SchoolWebAppClient** : Client MVC ASP.NET Core consommant l'API

## Lancement
1. Clic-droit sur la solution → Définir les projets de démarrage → Plusieurs projets
2. SchoolAPI : Démarrer | SchoolWebAppClient : Démarrer
3. `Add-Migration InitialCreate` puis `Update-Database` dans SchoolAPI
